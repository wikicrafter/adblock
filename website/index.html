Installation Guide

Step 1: Download & Extract

Download the .7z file from the download section below. Use 7-Zip (Windows) or The Unarchiver (Mac) to extract.

Why .7z format? Better compression = smaller download = faster installation.

Step 2: Enable Developer Mode

Open your browser and navigate to the extensions page:

  • Chrome: chrome://extensions/
  • Edge: edge://extensions/
  • Brave: brave://extensions/

Toggle Developer mode ON (usually in top-right corner).

Step 3: Load Extension

  1. Click "Load unpacked" button
  2. Select the extracted AdBlockX Chromium folder
  3. Extension will appear in your extensions list
  4. Pin the extension to your toolbar for easy access

HTTPS Everywhere automatically upgrades HTTP connections to secure HTTPS. It works on two levels:
  • Network level: Upgrades page navigations from http:// to https://
  • Content level: Rewrites links on pages you visit to use HTTPS

Enable it in Settings → Advanced Privacy → HTTPS Everywhere toggle.

AdBlockX fetches the community blocklist from GitHub via jsDelivr CDN once every 30 days. It validates:
  • Only valid DNS domain names are accepted
  • Protected domains (Google, GitHub, etc.) are excluded
  • Maximum 5,000 rules to prevent abuse
  • No duplicate rules are added

The sync is completely anonymous with no user identification.

Stealth Mode bypasses anti-adblock detection systems that some websites use. When enabled, AdBlockX:
  • Mocks anti-adblock libraries (blockAdBlock, FuckAdBlock, etc.)

Toggle it on in the popup (amber/gold switch). May occasionally break complex web apps.
