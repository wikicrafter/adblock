Installation Guide

The download is `.7z` because it offers better compression than ZIP and keeps the package size small for fast delivery. Use 7-Zip (free) to extract on Windows, macOS, or Linux.

Step 1: Download & Extract

Download the .7z file from the Download section. Extract it to a permanent folder.

Step 2: Install on Chrome/Edge/Brave

  1. Open chrome://extensions/ (or equivalent).
  2. Enable Developer mode.
  3. Click "Load unpacked" and select the extracted folder.
  4. If you don't have 7-Zip installed, download from 7-Zip.
  5. Pin the AdBlockX shield to your toolbar.
